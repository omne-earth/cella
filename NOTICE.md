# Notice

cella is a project of Omne, a 501(c)(3) nonprofit organization.

cella is a work in progress. It is not ready for production use.

- The interfaces, the file formats, and the security posture can
  change without a deprecation period.
- The confinement of the thin-CLI set is partial. The plan and the
  progress are tracked in tasks/PHASE2-security.md.
- Do not place production workloads, sensitive data, or untrusted
  adversarial workloads on cella at this stage.

Experimentation is welcome. Run the batteries (TESTING.md), read
the documents (docs/), and report what breaks.
