# bwrap profile for cella-probe: the diagnostics. Each probe opens
# /dev/kvm itself, and freeze-thaw-clock and wallclock launch the
# sibling cella-vmm through the flag interface and read its
# console. Jailed since the join's first pass (2026-09-03); the
# earlier "instrument, not product" exception is retired -- every
# persona but the shim runs confined.
#
# The dynamic parts are bound by the consumer: CELLA_HOME read-only
# (the goldens), and the directory of the binary itself read-only
# (the sibling VMM). /tmp is the host's, read-write, not a tmpfs:
# a failed probe keeps its logs there and names the path.
# /sys/devices/system/clocksource: the probe reports the host's
# clocksource beside the guest's. dev: the probe launches the VMM
# with a null stdin, and /dev/null must exist for that.

unshare-user
unshare-pid
unshare-ipc
unshare-uts
unshare-cgroup

dev
dev-bind /dev/kvm

ro-bind /lib
ro-bind /usr/lib
ro-bind /lib64
ro-bind /sys/devices/system/clocksource
bind /tmp

proc
new-session
