# bwrap profile for cella-network: the translator (1.6.14e), one
# process per machine, machine-lifetime, no capability. It holds
# the machine's edges: edge.sock under the machine directory, the
# wires under CELLA_HOME/wires, and the world side over ordinary
# sockets in the host network namespace. Jailed since the join's
# first pass (2026-09-03): the file capability is gone, thus the
# user namespace costs it nothing. Its identity is its machine's
# sub-uid, mapped by the spawn with the VMM's own handshake: an
# escapee from the frame parser lands as one machine, with that
# machine's directory and the shared wires directory, never as the
# operator. This jail nests inside that namespace.
#
# The dynamic part (CELLA_HOME, resolved at run time) is not named
# here: the consumer binds cella_libs::machine::home() read-write
# (the machine directory, the wires directory, the audit book).
#
# No unshare-net: the world sockets and the knock listeners live in
# the host network namespace by design. No unshare-pid: the
# translator writes its own pid to edge.pid and the machine verbs
# kill it by that number; a pid namespace would make the number a
# lie. No die-with-parent: bwrap's parent is the start verb, which
# exits at once, and that flag would kill the translator with it
# (measured 2026-09-03: PR_SET_PDEATHSIG in bwrap, SIGKILL on the
# verb's exit). The machine verbs own the translator's life.

unshare-user
unshare-ipc
unshare-uts
unshare-cgroup

ro-bind /lib
ro-bind /usr/lib
ro-bind /lib64

proc
tmpfs-tmp
new-session
