# bwrap profile for cella-doctor (1.6.14a): check reads host facts,
# fix repairs what the uid can, verify audits the goldens and the
# machines. It needs the whole home tree read-write (fix writes
# goldens and manifests) and /proc for host facts.
#
# Jailed since the join's first pass (2026-09-03): fix runs nothing
# (it prints the repairs as one script), thus nothing in doctor
# needs a setuid helper. check reads /etc/subuid and /etc/subgid,
# /sys/module for the nested-kvm parameter, and /usr/bin and
# /usr/sbin for the presence of the mapping helpers and of bwrap
# (`bwrap --version` runs inside the jail; it prints and exits).
# The consumer binds CELLA_HOME read-write (the audit book, the
# goldens fix would name).

unshare-user
unshare-pid
unshare-ipc
unshare-uts
unshare-cgroup

ro-bind /lib
ro-bind /usr/lib
ro-bind /lib64
ro-bind /usr/bin
ro-bind /usr/sbin
ro-bind /etc/subuid
ro-bind /etc/subgid
ro-bind /sys/module

dev-bind /dev/kvm

proc
tmpfs-tmp
new-session
